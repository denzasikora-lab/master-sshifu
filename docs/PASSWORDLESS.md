# Запуск без повторного пароля на Mac

Системные TUN, маршруты и DNS требуют административных прав. macOS должна
один раз разрешить установку помощника. После этого пароль для ежедневного
запуска, остановки, состояния и проверки установки не нужен.

## Установка

Среда: терминал Mac, каталог `~/Documents/dev/projects/master-sshifu`.
Сначала завершите обычную установку клиента и VPS по [INSTALL](INSTALL.md).
Нужны личный `config.json`, правила, проверенный `vendor/sing-box` и его
`provenance.json`. Рабочую Amnezia во время установки можно оставить включенной.
Собственный активный сеанс Master SSHifu сначала остановите.

```sh
sudo "$PWD/.venv/bin/python" "$PWD/tools/install_launcher.py"
```

Введите пароль администратора только в терминале. Команда не запускает VPN,
не меняет маршруты и не отключает Amnezia/Happ. Она проверяет конфигурацию,
движок и защищенность системного Python, создает копию и проверяет sudoers
через `visudo` до установки и после нее. При штатно обработанной ошибке
прежняя копия и прежняя политика восстанавливаются.

На этом Mac проверен Python Apple 3.9.6 из Command Line Tools. Он используется
только системной копией, изолированно с `-I -S -B`. Путь закрепляется при
установке; исполняемый файл, стандартная библиотека и их родители должны
принадлежать root и не допускать запись для группы или остальных пользователей.
Для рабочего клона и обычных команд сохраняется требование Python 3.12+.
Если Command Line Tools отсутствуют, установите `xcode-select --install`.
Небезопасный интерпретатор из Homebrew или `.venv` в разрешение не подставляется.

Проверка установленного разрешения без запуска сети:

```sh
./sshifu check
```

Ожидается JSON с `installed: true`, `passwordless: true`, `network_changed: false`.
Флаг `passwordless` означает, что фиксированная команда реально выполнена
через `sudo -n -k`, без использования сохраненной sudo-авторизации, а не только
наличие файла конфигурации. Доступность VPS,
работа YouTube и Speedtest этой командой не проверяются.

## Ежедневное использование

Когда готовы к переходу, самостоятельно отключите другой системный VPN.
Затем в каталоге проекта:

```sh
./sshifu
```

Ожидается короткий цветной вывод подготовки и включения. Пароля и KEEP нет,
сеанс постоянный до Ctrl+C. Защитник и подробные журналы сохраняются.
При конфликте с другим VPN команда уведомляет и выходит без его отключения.

Остановка из другого терминала:

```sh
./sshifu stop
./sshifu status
```

Запрос остановки не означает, что очистка уже закончилась: проверьте итоговое
состояние. Диагностика по-прежнему собирается обычным пользователем:

```sh
.venv/bin/python vpn.py diagnose
```

## Граница разрешения

- Системная копия: `/Library/PrivilegedHelperTools/master-sshifu`.
- Узкое правило: `/private/etc/sudoers.d/master-sshifu`.
- Разрешенный помощник: фиксированный `launch` внутри системной копии.
- Допустим ровно один аргумент: `connect`, `stop`, `status` или `check`.
- Команда закреплена за учетной записью, выполнившей установку.
- В правиле нет шаблонов `*`, общего Python, shell или `NOPASSWD: ALL`.
- Другие команды sudo по-прежнему требуют обычной авторизации.

Код, бинарный файл, конфигурация и правила копируются в каталог root.
Приватные SSH-ключи туда не копируются: SSH работает от исходного пользователя.
Файлы рабочего клона, его `.venv` и `PYTHONPATH` не загружаются с повышенными
правами. Установка и обновление не выполняются одновременно с активным
подключением помощника.

Файлы `config.json`, локальные правила и код в системной копии являются снимком.
После изменения исходников или личных настроек сначала остановите свой VPN,
затем повторите установку с одним административным подтверждением.
Обычный `git pull` сам системную копию не обновляет.

## Удаление и возврат обычного sudo

Среда: Mac, каталог проекта. Остановите собственный сеанс, затем:

```sh
sudo "$PWD/.venv/bin/python" "$PWD/tools/install_launcher.py" --remove
```

Удаляются только правило Master SSHifu и его системная копия. Исходники,
личная конфигурация и SSH-ключи остаются. После удаления возможен прежний
ручной запуск `sudo .venv/bin/python vpn.py connect`.
