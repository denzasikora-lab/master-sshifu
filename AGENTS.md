# Правила Master SSHifu

- Комментарии, описания и документация пишутся на русском языке.
- Используйте букву е без точек и обычный дефис.
- Все регрессионные проверки находятся в tests/test_all_regressions.py.
- Не включайте в Git config.json, ключи, бинарные файлы, журналы и личные адреса.
- Не отключайте чужие VPN и не заменяйте их маршруты автоматически.
- Проверка SOCKS не является приемкой системного режима.
- Закрытые SSH-ключи используются по пути; их содержимое не читается и не копируется.
- Системные сетевые испытания выполняются только по явному запросу пользователя.
