# Master SSHifu

SSH VPN для macOS: обычные приложения используют системный TUN, трафик
передается по OpenSSH, а домены `.ru`, `.su` и `.рф` идут напрямую.
TCP и UDP поддерживаются через sing-box и UDP-over-TCP v2.

```text
Master SSHifu: подготовка...
Master SSHifu: включено.
```

Подготовка голубая, включение зеленое, предупреждения желтые, ошибки красные.
В файлах и при `NO_COLOR=1` управляющие коды цвета не добавляются.

## Установка с нуля

**[Полная инструкция: каждый шаг на Mac и VPS](docs/INSTALL.md)**.

Инструкция включает установку Python, Git и sing-box, создание SSH-ключа,
проверку ключа сервера, отдельного пользователя Linux, службу systemd,
клиентскую конфигурацию, пробный SOCKS, системное подключение, проверку ru,
YouTube и Speedtest, остановку и удаление.

| Компонент | Требования |
| --- | --- |
| Клиент | Mac, Python 3.12+, системный OpenSSH, права sudo для TUN |
| Проверенная клиентская среда | macOS 26 arm64, Python 3.14 |
| VPS | Ubuntu 22.04+ или Debian 12+, systemd, OpenSSH, доступ в интернет |
| Архитектуры установщика | macOS arm64/amd64, Linux arm64/amd64 |
| Движок | sing-box 1.14.3 с закрепленными SHA256 |
| Пакеты pip | Не нужны, используется стандартная библиотека Python |

Поддержка архива другой архитектуры не означает приемку системного VPN на ней.
Системный клиент Linux/Windows и графический интерфейс в проект не входят.

## Повседневный запуск после установки

Среда: терминал Mac, каталог клона `master-sshifu`.

```sh
sudo "$PWD/.venv/bin/python" "$PWD/vpn.py" connect
```

Другой системный VPN нужно отключить вручную. При конфликте основных маршрутов
команда сразу сообщает об обнаруженном VPN и завершается без ожидания,
изменения его маршрутов и DNS. Другой протокол сам по себе не делает два
системных VPN совместимыми. Прокси-режим можно использовать отдельно.

После готовности сеанс работает до Ctrl+C. KEEP и начальных запросов к
YouTube, Speedtest или сервисам определения IP нет. Терминал остается открытым.
Фоновый контроль выхода начинается через 15 секунд после готовности.

## Как устроено подключение

```text
Приложения Mac -> TUN sing-box -> OpenSSH -L -> VPS:127.0.0.1:43190 -> интернет
                       |
                       +-> домены ru/su/рф -> физический интерфейс Mac
```

Шифрование и аутентификацию обеспечивает OpenSSH. Собственный шифр не создается.
VPS слушает SOCKS только на localhost; открывать 43190 в интернет не требуется.
На клиенте сервер SSH и прямой выход привязаны к физическому интерфейсу.

Это разделение по домену и явным IP-правилам, а не географическая база России.
Российский сайт на `.com` и внешний ресурс внутри страницы `.ru` могут идти
через SSH. Пользовательские DoH-настройки, IP-ссылки и сохраненные соединения
требуют отдельной проверки. UDP идет поверх TCP и чувствителен к потерям.
SSH не маскируется под HTTPS и может блокироваться в конкретной сети.

## Откат и журналы

Независимый защитник контролирует активность управляющего процесса и удаляет
его собственные маршруты при аварии. Дочерние процессы и временный DNS
привязаны к локальным каналам, а не к доступности чата или внешнего сервиса.
Чужие маршруты не заменяются. После сна или смены сети может потребоваться
повторный запуск. Автоматическое включение Amnezia/Happ отключено.

Читаемые отчеты системного сеанса:

- `/private/var/run/ssh-split-session.json`;
- `/private/var/run/ssh-split-session.log`;
- `/private/var/run/ssh-split-vpn.json`.

Старый служебный префикс `ssh-split` сохранен для совместимости. Логи и личная
конфигурация не входят в Git. Движок пишет предупреждения и ошибки; подробный
журнал каждого соединения в обычном сеансе отключен.

В журнале есть этап сбоя, traceback, коды завершения процессов, результаты
фоновых проверок, переподключения и результат очистки. История системного
сеанса ограничена ротацией: текущий файл до 1 МиБ и три предыдущих файла.

Собрать диагностику после ошибки, без sudo и без подключения к интернету:

```sh
.venv/bin/python vpn.py diagnose
```

Команда напечатает путь к JSON в `.runtime`. Файл может содержать IP и локальные
пути; проверьте его перед публикацией. Ключи SSH и `config.json` не собираются.
